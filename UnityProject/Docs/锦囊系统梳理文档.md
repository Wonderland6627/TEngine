# 锦囊系统梳理文档

## 一、系统概述

锦囊系统是游戏中的辅助奖励机制，当玩家处于劣势时（城堡被敌人占领），系统会弹出锦囊选择界面，玩家可以选择一个锦囊来扭转战局。锦囊分为即时生效和持续生效两种类型。

- `durations`：数组长度为3，对应三种稀有度的持续时间（秒），0表示即时生效
- `needAds`：数组长度为3，对应三种稀有度是否需要看广告才能获得

### 4.3 锦囊生成逻辑

```76:106:Assets/GameScripts/HotFix/GameLogic/SlimeGame/SlimeReward.cs
        public List<RewardAction> GetRewardActions(List<RewardConfig> rewardConfigs)
        {
            //获取随机3个RewardConfig, 再随机一个稀有度(稀有度Rare = 0.5, Epic = 0.4, Legendary = 0.1), 组成3个RewardAction
            List<RewardAction> actions = new List<RewardAction>();
            if (rewardConfigs == null || rewardConfigs.Count < 3)
            {
                return actions;
            }

            var selectedConfigs = new List<RewardConfig>();
            var tempConfigs = new List<RewardConfig>(rewardConfigs);
            
            for (int i = 0; i < 3 && tempConfigs.Count > 0; i++)
            {
                int randomIndex = Random.Range(0, tempConfigs.Count);
                selectedConfigs.Add(tempConfigs[randomIndex]);
                tempConfigs.RemoveAt(randomIndex);
            }

            foreach (var config in selectedConfigs)
            {
                actions.Add(new RewardAction
                {
                    actionUID = config.GetHashCode(),
                    config = config,
                    rarity = GetRandomRarity()
                });
            }

            return actions;
        }
```

**生成规则**：
1. 从所有锦囊配置中随机选择3个不重复的锦囊
2. 为每个锦囊随机分配一个稀有度（按概率分布）
3. 返回3个 `RewardAction` 供玩家选择

## 五、触发时机

### 5.1 触发条件

锦囊窗口在以下情况下会被触发：

```31:51:Assets/GameScripts/HotFix/GameLogic/SlimeGame/World_GameReward.cs
        // 当玩家的城堡被敌人占领时触发 现用于检查锦囊触发时机
        public void TryShowAdsRewardWindow()
        {
            occupiedCastleTimes++;
            if (GameModule.Debugger.ActiveWindow) 
            {
                ShowAdsRewardWindow();
                return;
            }
            
            if (Time.time - lastTriggerTime < adsRewardWindowTriggerInterval) return; // adsRewardWindowTriggerInterval秒内只触发一次
            List<UnitType> unitTypes = castles.Select(castle => castle.occupiedUnitType).Distinct().ToList();
            if (unitTypes.Count == 1) return; // 游戏已经结束 不再弹出锦囊

            bool condition1 = occupiedCastleTimes % 2 == 1; // 被敌人占领的城堡次数为奇数
            bool condition2 = castles.FindAll(c => c.isOccupied && c.occupiedUnitType == UnitType.Player).Count == 1; // 玩家只剩下一个城堡了
            if (condition1 || condition2) //满足任意一个条件就能触发锦囊
            {
                lastTriggerTime = (int)Time.time;
                ShowAdsRewardWindow();
            }
        }
```

**触发条件详解**：

1. **调试模式**：如果调试窗口开启，直接触发（无限制）
2. **时间间隔限制**：距离上次触发至少间隔 `adsRewardWindowTriggerInterval` 秒（20秒）
3. **游戏状态检查**：如果游戏已结束（所有城堡被同一方占领），不触发
4. **条件1**：被敌人占领的城堡次数为奇数（`occupiedCastleTimes % 2 == 1`）
5. **条件2**：玩家只剩下一个城堡（`玩家城堡数量 == 1`）

**满足条件1或条件2即可触发**

## 九、系统特点

1. **劣势触发**：只在玩家处于劣势时触发，增加游戏策略性
2. **随机性**：锦囊选择和稀有度都是随机的，增加游戏趣味性
3. **广告机制**：高稀有度锦囊需要看广告，平衡游戏经济
4. **持续效果**：部分锦囊有持续时间，需要玩家在有效期内利用
5. **即时效果**：大部分锦囊即时生效，快速扭转战局

---

## 十、注意事项

1. **游戏状态检查**：游戏结束时不会触发锦囊
2. **时间间隔限制**：防止频繁弹出，影响游戏体验
3. **空值检查**：所有能力实现都有空值检查，防止崩溃
4. **效果重置**：持续效果会在时间到期后自动重置所有相关参数
5. **调试模式**：调试模式下可以无限制触发锦囊
