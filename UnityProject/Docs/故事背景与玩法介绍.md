# 故事背景与玩法介绍

> 本文档为游戏世界观与核心玩法的基准设定文档，后续系统设计、关卡策划、美术风格等均以此为参考。

## 1. 游戏概述

**史莱姆工厂** 是一款治愈萌系的轻策略休闲微信小游戏。

玩家将扮演蓝晶族的指挥官，在一片由果冻和水晶构成的奇幻大陆上，通过派遣可爱的史莱姆小队占领城堡、开辟道路，用自己的色彩点亮每一寸土地。

- **类型**：轻策略 + 领地占领
- **平台**：微信小游戏（兼容抖音、B站小游戏）
- **操作**：拖拽派兵，单手可玩
- **单局时长**：1-3 分钟
- **目标用户**：休闲玩家，以 30-45 岁女性为主

---

## 2. 世界观

### 果冻大陆

在云海之上，漂浮着一片由柔软果冻和透亮水晶凝结而成的大陆——**果冻大陆**。

这里没有坚硬的岩石，也没有锋利的尖刺，到处都是 Q 弹的地面、晶莹的河流和五彩的森林。大陆上生活着一种天生乐观、圆滚滚的生物——**史莱姆**。

史莱姆们以颜色区分种族，每个种族都有自己独特的性格和天赋。它们各自守护着属于自己色彩的家园城堡，在果冻大陆上快乐地生活。

直到某天，云海深处漂来一股紫黑色的雾气。它不吵不闹，却会悄悄把城堡里的\"色彩\"抹掉，把原本清澈的颜色染成单调的暗色——史莱姆们把它叫做**黯潮**。

黯潮背后只有一个反派种族：紫黑色的史莱姆。它们能把见过的技巧\"学走\"，让被侵染的城堡在某些关卡里表现出不同的倾向（例如更偏生产、更偏速度、更偏干扰……具体以关卡配置为准）。为了守住自己的家园，也为了把被黯潮弄乱的城堡重新修好，各色史莱姆不得不踏上果冻小路，去夺回、修复、点亮每一座城堡的色彩。

这不是残酷的战争，而是一场关于\"守护、修复与色彩\"的温柔冒险。

## 3. 种族设定

果冻大陆上的史莱姆以颜色分族。大多数族群彼此友好，会因为口味、风景和生活习惯不同而各自聚居；真正让大家头疼的，只有一个反派种族——紫黑色的史莱姆。

> **能力设定（轻度）**：每个颜色的史莱姆都有自己的\"能力偏好方向\"（例如更擅长生产、行军、占领、防守、支援、干扰等）。关卡可按需要配置：让某些偏好更明显，或让反派在不同关卡\"仿造\"不同颜色的偏好表现。

### 3.1 蓝晶族（Blue）`当前玩家方已实现`

| 项目 | 描述 |
|------|------|
| 代表色 | 天蓝 |
| 元素 | 水 |
| 性格 | 沉稳可靠、乐于助人 |
| 特质 | 均衡型，攻守兼备，适合新手 |
| 潜在偏好 | 防御力稍高、行军耐久 |

蓝晶族像清澈的溪水一样温和，是果冻大陆上最让人安心的邻居之一。你将从蓝晶族的工坊出发，学习如何调度史莱姆小队、修复被侵染的城堡。蓝晶族的城堡周围总是环绕着宁静的水晶溪流，能让路过的史莱姆也放慢一点点脚步。

### 3.2 樱粉族（Pink）`待扩展`

| 项目 | 描述 |
|------|------|
| 代表色 | 樱粉 |
| 元素 | 花 |
| 性格 | 温柔热情、喜欢分享 |
| 特质 | 治愈型，擅长恢复与支援 |
| 潜在偏好 | 城堡回复速度快、可为友军增益 |

樱粉族居住在果冻大陆的花丛深处。它们有着淡淡的花香，经过的道路上会留下片片花瓣。据说樱粉族的城堡里总是开满了永不凋谢的水晶花。

### 3.3 翠叶族（Green）`待扩展`

| 项目 | 描述 |
|------|------|
| 代表色 | 翠绿 |
| 元素 | 森 |
| 性格 | 活泼好动、充满生机 |
| 特质 | 生长型，擅长生产与扩张 |
| 潜在偏好 | 史莱姆生产速度快、数量优势 |

翠叶族栖息在果冻大陆茂密的水晶丛林中。它们精力充沛，繁殖能力强，总是成群结队地行动。翠叶族的城堡被藤蔓和嫩芽包裹，生机勃勃。

### 3.4 赤焰族（Red）`待扩展（世界观中为普通种族）`

赤焰族热情、直接，喜欢把工坊里的热力开到最大。它们不是反派，只是做事很有冲劲，遇到黯潮时也会第一时间冲上去把城堡夺回来。

| 项目 | 描述 |
|------|------|
| 代表色 | 赤红 |
| 元素 | 火 |
| 性格 | 热血冲动、勇往直前 |
| 特质 | 攻击型，擅长正面冲锋 |
| 潜在偏好 | 攻击力高、行军速度快 |

赤焰族身上散发着温暖的微光，有着用不完的热情；它们喜欢用最快的方式解决问题，也因此常常成为\"先锋\"。

### 3.5 金雷族（Yellow）`待扩展`

| 项目 | 描述 |
|------|------|
| 代表色 | 金黄 |
| 元素 | 雷 |
| 性格 | 机敏灵活、风驰电掣 |
| 特质 | 速度型，擅长快速穿插 |
| 潜在偏好 | 行军速度极快、攻击间隔短 |

金雷族来自果冻大陆云层最高处的雷电平原。它们像闪电一样迅速，总是第一个抵达关键路口，帮大家把局势\"拉回来\"。

### 3.6 黯渊族（PurpleBlack）`反派种族，待扩展`

黯渊族是黯潮的源头。它们的颜色介于紫与黑之间，像夜里打翻的墨水。

它们最可怕的地方不是力气，而是\"学得快\"：黯渊族能仿造它们见过的能力偏好，让自己或被侵染的城堡在某一关卡中表现出类似的特性（例如偏向生产、偏向速度、偏向干扰……具体以关卡配置为准）。

对玩家来说，黯渊族更像一种\"会变化的难题\"：同样的关卡结构，在不同配置下可能呈现不同的反派倾向，需要你用更温柔也更聪明的调度去化解。

## 4. 核心玩法

### 4.1 城堡

城堡是史莱姆们的**工坊与家园据点**：能生产、能驻扎、也能作为前进路上的补给站。谁修复并点亮了城堡，谁就能在这里继续生产自己的史莱姆小队。

**城堡类型**：

| 类型 | 说明 |
|------|------|
| **巢穴 (Nest)** | 可以自动生产史莱姆的城堡，是核心的进攻与防守据点 |
| **哨塔 (Tower)** | 不生产史莱姆的中立建筑，占领后作为战略中转站 |

**占领机制**：

- 每座城堡有一个"占领值"，代表当前驻守的史莱姆数量
- 己方史莱姆到达城堡时，占领值 +1
- 敌方史莱姆到达城堡时，占领值 -1
- 当占领值降为 0 时，城堡归属权切换
- 空城堡需要累积一定数量的史莱姆才能完成占领

### 4.2 道路与行军

城堡之间由果冻小路相连，史莱姆只能沿道路行进。

**派兵操作**：

1. 在己方城堡上按住并拖拽
2. 沿拖拽方向会自动锁定目标城堡（目标需在拖拽方向约 20° 范围内，且有道路相连）
3. 松手后，城堡中的史莱姆将沿道路依次出发前往目标
4. 若目标城堡不直接相连，史莱姆会自动寻找中转城堡前进

**道路碰撞**：

- 在同一条道路上，相向而行的敌对史莱姆相遇时会互相抵消（一换一）
- 这意味着派兵路线的选择至关重要——可以通过巧妙调配兵力，拦截敌人的进攻

### 4.3 战斗与占领

**自动生产**：

- 巢穴型城堡会按固定间隔自动生产史莱姆
- 城堡内驻守的史莱姆越多，生产速度越快（存在加速上限）
- 不同种族和关卡对生产速度有不同的配置

**AI 对手**：

- 黯潮势力由 AI 控制，会定时评估局势并发动进攻
- AI 会优先攻击离自己最近的玩家城堡或空城堡
- 当 AI 占据优势时，会适当放慢进攻节奏（给玩家喘息空间）

### 4.4 胜利条件

- **胜利**：占领关卡中所有城堡
- **失败**：所有城堡被黯潮势力占领

当玩家胜利时，所有城堡会依次绽放出胜利的色彩特效，然后进入结算画面领取奖励。

## 5. 成长与资源

### 5.1 关卡推进

- 游戏采用关卡制，关卡配置在 `levels.json` 中
- 每个关卡定义了城堡数量、位置、道路连接、初始归属及各方生产/攻击节奏
- 关卡由简到难，后期城堡数量更多、路线更复杂、AI 更具挑战性

### 5.2 金币与体力

| 资源 | 获取方式 | 用途 |
|------|----------|------|
| **体力** | 每日登录赠送、通关返还部分、广告奖励、每日宝箱 | 进入关卡消耗 |
| **金币** | 通关奖励（首通加成）、广告翻倍、每日签到 | 后续系统使用（预留） |

**通关奖励公式**：

- 基础金币 = `baseCoin + coinPerLevel × (关卡ID - 1)`
- 首通奖励 = 基础金币 × 首通倍率
- 体力返还 = 消耗体力 × 返还比例
- 广告翻倍 = 基础金币 × (广告倍率 - 1)

### 5.3 每日签到

- 每日登录可领取签到宝箱，获得金币奖励
- 由 `DailyChestManager` 管理，每日限领一次

## 6. 后续扩展方向

以下为初步规划的扩展方向，具体设计需另建独立文档：

| 方向 | 简述 |
|------|------|
| **多彩种族上线** | 逐步开放樱粉族、翠叶族、赤焰族、金雷族等，引入轻度差异化的\"能力偏好方向\" |
| **反派能力配置** | 关卡可配置黯渊族本关偏好的能力倾向（例如偏生产/偏速度/偏干扰等），形成\"同地图不同解法\" |
| **图鉴系统** | UI 中已预留"图鉴"Tab，可收录已解锁的种族、城堡外观等 |
| **抽奖/扭蛋** | UI 中已预留"抽奖"Tab，可作为获取装饰、皮肤的入口 |
| **城堡装饰** | 自定义城堡外观，贴合治愈萌系定位，增强收集感 |
| **社交排行** | 当前已有排行榜与好友排行，可进一步扩展社交互动 |
| **赛季/章节** | 以章节形式推出新关卡包，每个章节讲述不同种族的小故事 |
